# 一、任務目標

為香港小學三年級數學「3N5 分數(一)」第 12 課「分數的認識(二)」製作互動頁，主題名稱：

1. 認識「分數作為一組物件（整體）的部分」
2. 認識「一組物件的幾分之幾是多少」

fraction-set-objects.html

技術與風格對齊本倉庫既有教學頁（如 air-pressure-drink-box.html）：

- 繁體中文介面（lang="zh-Hant"）
- CSS 變數定義色彩；背景用柔和漸層（避免紫白／奶油 terracotta／報紙風）
- 字型可用系統中文字型堆疊，避免硬依賴外網字型（Google Fonts 可選但不必要）
- 觸控優先、響應式；桌面與手機皆可操作
- 無登入、無追蹤、不使用 localStorage 收集資料

- 至少 2～3 個有意義的微動畫（選中高亮、等分線淡入、正確慶祝／錯因提示），動畫服務理解而非雜訊

# 二、必守教學準則（不可違反）

## 2.1 離散模型核心

- 把「一組物件」看作一個整體。例如把 10 個水果看作一個整體。
- 用分數表示某部分佔全組物件的幾分之幾時：
  - 分母 = 全組物件的數量
  - 分子 = 該部分在全組中所佔的數量
- 全組物件的大小不一定相同，只要是同類便可。
- 必須強調「等分」：把一組物件等分成若干份時，每份的【物件數量】必須相同。

## 2.2 數學語言（介面必須使用）

等分、整體、部分、分數、分子、分母、分線。
讀法範例：「十分之七」「蘋果佔全部水果的十分之七」。

## 2.3 明確納入

概念 A（水果盒）：
- 給一組混合物件，寫出某種物件佔整體的分數
- 零分數：分子是 0、分母 ≠ 0 時，分數等於 0（例如 0/9 = 0）
- 整體定義會影響分母：例如「全部水果」與「全部蘋果」分母不同

概念 B（玩具店／找數量）：
- 給定「一組物件的 a/b」，用【圖示等分】找出數量
- 分母 b = 把全部物件等分成 b 份；分子 a = 取其中 a 份
- 允許多種等分方式（橫分、直分、十字分等），只要每份數量相等即可
- 【不宜用乘法／除法計算式講解】；必須透過畫面分組、圈選、著色來理解
- 現階段不要求最簡分數；若學生答 3/18 或看出是 1/6 都可接受（挑戰回饋時兩者皆算合理）

## 2.4 明確排除（不要做）

- 連續圖形模型（蛋糕／手工紙等分面積）作為主軸（可一句對比說明，但不要做成關卡）
- 等值分數、擴分、約分
- 假分數、帶分數
- 同分母／同分子大小比較專題
- 分數加減運算
- 代數化「總數 × 分子 ÷ 分母」作為主要解法提示

## 2.5 常見誤區（挑戰關必須針對回饋）

1. 錯把「餘下數量」當分母（例如吃去 2 粒、餘下 6 粒，誤寫 2/6；正解分母應是全部 8）
2. 錯把「另一子集合」當分母（例如紅星 2、藍星 5、共 7；誤寫 2/5；正解 2/7）
3. 忽略「整體」定義改變時分母也改變（全部水果 vs 全部蘋果）
4. 以為分子是 0 的分數「沒有意義」；應認識 0/n = 0（n ≠ 0）

# 三、畫面流程與互動規格

流程：
開場說明（含連續 vs 離散對比）→ 模式 A 引導示範 → 模式 A 練習 → 模式 B 引導示範 → 模式 B 練習 → 挑戰關卡 → 重點回顧（可重播迷你解說）

導覽可切換；**每個模式進入練習前必須先走完引導示範**（教師「解說模式」開啟時逐步按「下一步」；關閉時可自動播放）。

## 3.0 解說腳本（必做，旁白寫進 UI）

### 開場對比（約 15 秒／3 步）
1. 「上一課我們用一塊蛋糕（面積）看分數。」（左：連續圖示）
2. 「這一課改用一盒水果（個數）看分數。」（右：離散圖示高亮）
3. 「一組物件也可以是一個『整體』。分母看全部有多少個，分子看這一部分有多少個。」

### 模式 A 引導示範（水果 10 個，蘋果 7 個）— 逐步旁白，同步動畫
1. 「水果禮盒是一組物件，我們把它看作一個整體。」→ 禮盒外框脈動
2. 「先數全部水果：一共有 10 個。這個 10 就是分母。」→ 全部高亮，分母格填入 10
3. 「再數蘋果：有 7 個。這個 7 就是分子。」→ 僅蘋果高亮，分子格填入 7
4. 「中間這條是分線。蘋果佔全部水果的十分之七。」→ 分數卡完整顯示並讀出
5. 「記住：分母問『整體是甚麼』——這裏的整體是全部水果，不是其他水果的數量。」

### 模式 B 引導示範（10 的 3/5）— 禁止乘除算式作主解說
1. 「題目：10 個布娃娃的五分之三是多少？」
2. 「看分母 5：把 10 個等分成 5 份。」→ 出現 5 個分組框
3. 「檢查：每份都是 2 個，才算等分。」→ 每份標數量
4. 「看分子 3：取其中 3 份。」→ 3 組高亮
5. 「數一數高亮的：一共 6 個。所以答案是 6。」→ 答案放大出現

### 錯因對照（挑戰關答錯時必播）
- 並排：正確分母（全部）綠框 vs 錯誤分母（餘下／另一種）淡化＋叉
- 旁白一句：「分母要用全部（整體）的數量，不能用餘下或其他種類的數量。」

### 教師控制
- 「解說模式」開關：開＝每步按下一步；關＝自動播完進練習
- 「重播解說」按鈕：可在練習中重看示範

## 3.1 開場說明

除 3.0 開場對比外，介面常駐提示句：
- 一組物件也可以是一個「整體」
- 分母看「全部有多少個」，分子看「這一部分有多少個」
- 等分時每份的個數要一樣多

## 3.2 模式 A：寫出分數（水果禮盒）

畫面：
- 中央是一盒／一盤水果（用簡單 SVG／Canvas／emoji 皆可，風格統一即可）
- 顯示多種水果（如蘋果、橙、香蕉、奇異果等），總數建議 8～12，可調
- 右側或下方顯示「分數卡」：分母、分子、分線，以及中文讀法
- 提示句：「先數全部水果（分母），再數指定水果（分子）」

互動：
1. 玩家點一種水果類型（或點選多個個體著色）
2. 即時更新分數：分子/分母，並以動畫標示「全部」與「部分」
3. 提供「出題」按鈕：隨機問「○○佔全部水果的幾分之幾？」玩家可輸入或點選分子分母
4. 答錯時給【針對性】提示（例如：「分母應是全部水果的數量，不是其他水果的數量」），不要只說「再試一次」
5. 至少一題分子為 0 的情境（禮盒中沒有某種水果）

教師可調（簡易控制列即可）：
- 總件數範圍約 6～20
- 顯示／隱藏提示
- 重置禮盒

內建例題素材（應用或變形）：
- 全部水果 10 個，蘋果 7 個 → 蘋果佔 7/10
- 橙的數量 → 橙佔全部的 ?/?
- 某種水果 0 個 → 0/n = 0
- 堂課變形：先問紅蘋果佔全部水果；再問紅＋青蘋果共佔多少；再改以「全部蘋果」為整體；再「多加 1 個紅蘋果」後分數如何變

## 3.3 模式 B：找出數量（等分一組物件）

畫面：
- 給定固定數量的相同物件（如布娃娃、陀螺、貼紙、朱古力豆），排成規則陣列以便畫等分線
- 題目格式：「____ 的 a/b 是多少？」
- 工具：等分份數選擇（對應分母）、圈選／著色其中幾份（對應分子）、確認答案

互動教學步驟（必須引導，不可跳過成計算）：
1. 看分母：把全部物件等分成 b 份（畫分隔線或分組框，動畫出現）
2. 檢查每份個數是否相同；不相同則提示重新等分
3. 看分子：取其中 a 份（高亮）
4. 數出高亮物件數量作為答案

允許多種等分幾何（至少支援兩種，例如橫分與直分）。只要每份數量相等且取 a 份，答案正確即通過。

內建例題素材：
- 10 的 3/5 → 等分成 5 份，每份 2，取 3 份 → 6
- 16 的 3/4 → 可橫／直／十字等分 → 12
- 18 的 5/6 → 送出 15；並可追問餘下佔全部的幾分之幾（3/18 或 1/6 皆可）
- 挑戰變形：14 粒等分成 7 份，比較兩人各取不同分子份數的數量（仍用圈選比較，不做抽象比大小單元）

## 3.4 挑戰關卡（4～6 題即可）

混合 A／B，必須包含：
1. 子集合當分母的誘答（紅星／藍星）
2. 餘下數量當分母的誘答（吃去荔枝）
3. 0/n = 0
4. 整體定義切換（全部水果 vs 全部蘋果）
5. 至少一題「找數量」等分題

每題答完顯示簡短「為什麼」說明（1～2 句），用物件圖回顧正確分母／等分。

## 3.5 重點回顧

結束頁用條列＋小圖總結（不要長文）：
1. 一組物件可看作一個整體
2. 分母＝全部數量；分子＝部分數量
3. 求「整體的 a/b」→ 先等分成 b 份，再取 a 份
4. 分子與分母相同時等於 1；分子是 0（分母≠0）等於 0（可輕提，不展開假分數單元）
5. 分數有意義的前提是先弄清楚「整體是甚麼」——沒說清楚整體，單看分數不知道實際有多少

# 四、UI／UX 細節

- 第一視埠：品牌／遊戲名「水果禮盒分數工坊」要清楚，一句副標說明學習目標，一個開始 CTA；不要塞統計列或一堆卡片
- 大按鈕、大點擊區，適合小三手指操作
- 顏色對比足夠；正確用綠系、提醒用暖橙，避免螢光紫光暈
- 分數顯示用清楚的直式分線排版（分子在上、分線、分母在下），並同步顯示「a/b」與中文讀法
- 提供「顯示提示／隱藏提示」「再玩一次」
- 無障礙：重要按鈕有文字，不只靠顏色；動畫可用 CSS，不依賴聲音

# 五、實作建議（技術）

- 單一 HTML 檔，內嵌 <style> 與 <script>
- 狀態可用簡單 JS 物件管理（mode、level、selectedIds、groups…）
- 物件用資料陣列描述（id、type、x、y 或 gridIndex），渲染到 DOM 或 canvas 皆可
- 若用 canvas／p5：點擊命中測試要準；若用 DOM：每個物件一個 button／可聚焦元素更佳（推薦 DOM 以便觸控與無障礙）
- 不要引入大型框架（React/Vue 等）
- 註解用繁中簡短說明關鍵教學邏輯（例如「為何這裡用全部數量當分母」）
